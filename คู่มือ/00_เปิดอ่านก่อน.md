# แผนที่โค้ด BDC POS

โฟลเดอร์นี้คือชุดที่ควรใช้ต่อและอัปขึ้น GitHub

## เปิดแอพ

เปิดไฟล์ `index.html` ใน Chrome

## โครงสร้าง

```text
BDC_POS_ใช้งานจริง_พร้อมพัฒนาต่อ/
  index.html
  หน้าตาแอพ/
    หน้าตาแอพทั้งหมด.css
  โค้ดระบบ/
    01_ตั้งค่าและตัวช่วยกลาง.js
    02_หลังบ้านจัดการร้าน.js
    03_รับออเดอร์และตะกร้า.js
    04_ล็อกอินและสิทธิ์.js
    05_โต๊ะครัวสถานะแคชเชียร์.js
    06_รายงานยอดขายและส่งออกไฟล์.js
  คู่มือ/
  สำรองไฟล์เดิม/
```

## แก้อะไรต้องเปิดไฟล์ไหน

| อยากแก้ | เปิดไฟล์ |
|---|---|
| Firebase URL, state กลาง, helper, โหลดข้อมูลเริ่มต้น | `โค้ดระบบ/01_ตั้งค่าและตัวช่วยกลาง.js` |
| Admin dashboard, ล้างข้อมูล, audit log, menu, topping, table, staff | `โค้ดระบบ/02_หลังบ้านจัดการร้าน.js` |
| หมวดเมนู, การเลือกเมนู, ตัวเลือก/ท็อปปิ้ง, เพิ่มลงตะกร้า | `โค้ดระบบ/03_รับออเดอร์และตะกร้า.js` |
| Login, Admin Test, permission, navigation | `โค้ดระบบ/04_ล็อกอินและสิทธิ์.js` |
| ผังโต๊ะ, ส่งครัว, สถานะ, ครัว, แคชเชียร์, ชำระเงิน | `โค้ดระบบ/05_โต๊ะครัวสถานะแคชเชียร์.js` |
| ยอดขาย, tabs รายงาน, export CSV, เริ่ม fetchInitialData | `โค้ดระบบ/06_รายงานยอดขายและส่งออกไฟล์.js` |
| สี ขนาด ระยะห่าง มือถือ/iPad | `หน้าตาแอพ/หน้าตาแอพทั้งหมด.css` |
| โครงหน้า ปุ่ม modal พื้นที่ HTML | `index.html` |

## ข้อควรจำ

- อย่าลบไฟล์ใน `สำรองไฟล์เดิม` ถ้ายังไม่ได้ขึ้น GitHub เรียบร้อย
- ระบบยังเป็น static HTML/CSS/JS เปิดใน Chrome ได้
- ถ้าจะให้ AI ช่วยแก้ ให้แนบโฟลเดอร์นี้หรือบอกให้ AI อ่าน `คู่มือ/คู่มือนักพัฒนาและAI.md` ก่อน
