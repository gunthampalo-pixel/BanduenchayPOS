# ขั้นตอนเอาขึ้น GitHub แบบง่าย

## สิ่งที่ต้องอัปโหลด

อัปโหลดทุกอย่างในโฟลเดอร์นี้:

`BDC_POS_ใช้งานจริง_พร้อมพัฒนาต่อ`

ไฟล์ที่สำคัญคือ:

- `index.html`
- `หน้าตาแอพ/หน้าตาแอพทั้งหมด.css`
- `โค้ดระบบ/*.js`
- `คู่มือ/*.md`

## วิธีทำแบบไม่ใช้ command line

1. เข้า GitHub
2. กด New repository
3. ตั้งชื่อ repo เช่น `bdc-pos`
4. กด Upload files
5. ลากไฟล์และโฟลเดอร์ทั้งหมดจากชุดนี้ขึ้นไป
6. Commit changes
7. ไป Settings > Pages
8. Source เลือก Deploy from branch
9. Branch เลือก main / root
10. รอ URL จาก GitHub Pages

## หลัง deploy

เปิด URL บนมือถือ/iPad/Chrome แล้วทดสอบ:

- Login
- สั่งอาหาร
- ครัว
- แคชเชียร์
- ยอดขาย
- Export CSV
